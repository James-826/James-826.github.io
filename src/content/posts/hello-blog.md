这个博客主要用来做两件事。

## 整理项目

GitHub 上堆了很多仓库，有的是做完了的，有的是做了一半就放下的。与其让它们躺在仓库列表里吃灰，不如给每个项目写一篇笔记：

- 这个项目做了什么
- 做到哪一步
- 为什么停下来了
- 我从中学会了什么

## 沉淀学习

每天学的内容很多，不写下来很快就忘了。以后我会把学习笔记也整理到这里，按主题归档，方便回看。

博客用 [Fuwari](https://github.com/saicaca/fuwari) 搭建，内容全部是 Markdown，托管在 GitHub Pages 上，写文章只需要在 `src/content/posts/` 里新建一个 `.md` 文件。
